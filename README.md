# Nera

A personal Codex concierge for finding options, comparing all-in prices and availability, contacting providers, negotiating within approved limits, preparing bookings, and monitoring outcomes.

## What it does

- searches information visible to the signed-in account;
- compares viable options by total price, availability, location, reviews, fees, and cancellation terms;
- searches Wolt Georgia for products, normalizes pack prices, compares delivery fees, and prepares reviewed carts;
- reviews conversations and drafts replies;
- prepares clarification questions;
- runs bounded non-binding provider negotiations after the mission is approved;
- finds Telegram communities by city or topic, searches their history, and posts approved focused questions;
- sends only an exact user-approved message to an exact recipient;
- searches Unison doctors and slots, then books only the exact reviewed appointment after confirmation;
- verifies booking or purchase confirmation and can monitor replies or changing availability;
- stops on login challenges, CAPTCHA, rate limits, or ambiguous recipients.

## Browser and privacy model

The plugin relies on the installed Chrome control capability and the user's existing browser sessions. It does not store credentials, inspect cookies, bypass access controls, or use unofficial social-network APIs.

Start a new Codex task after installation and invoke `social-web-assistant` or ask for social-site research/outreach directly.
